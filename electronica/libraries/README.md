# Librerías propias

Este proyecto usa únicamente librerías estándar de KiCad (ver
`electronica/kicad/fp-lib-table` y el informe en
`docs/informes/Parte_II_Informe.md`, sección 5). Esta carpeta queda
reservada por si en una revisión futura se agregan símbolos o footprints
propios (por ejemplo, un footprint específico para el módulo HW-393 en vez
del conector genérico usado actualmente).
